# Documentation Checklist Before Implementation

## Rule
Implementation is blocked until every checklist section is complete and approved.

Current status is tracked in the Structured Planning Review Status document.

## A. Product Clarity
- Vision statement finalized.
- MVP use cases listed and prioritized.
- Out-of-scope list approved.
- Success metrics defined.

## B. Requirements
- Functional requirements frozen for MVP.
- Non-functional requirements frozen for MVP.
- Error handling expectations documented.
- Clarification and confirmation behaviors documented.

## C. Architecture
- Component boundaries documented.
- Data flow documented.
- Skill contract schema defined.
- Memory model defined.
- Logging model defined.

## D. Safety And Privacy
- Risk classification matrix documented.
- Action permission levels documented.
- Sensitive operation policy documented.
- Data retention and deletion policy documented.

## E. Delivery Planning
- Milestones and phase exits documented.
- Test strategy documented.
- Definition of done documented.
- Rollout plan documented.

## F. Governance
- Decision log initialized.
- Change request process defined.
- Approval owners identified.
